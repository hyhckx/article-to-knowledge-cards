# Make Knowledge Cards

## Overview

把一篇文章压缩为一组可独立复习的知识卡片。每张卡片只讲一个知识点，包含四个固定字段：标题、核心知识、简明解释、例子或自测问题。严格忠于原文：不编造、不重复、信息不足时宁可少做也不凑数。

## 输入处理

- **粘贴文本**：直接使用。
- **本地文件**：用 Read 读取 `.md` 或 `.txt`（UTF-8）。读取失败时报告路径或编码问题，不要猜测内容。
- **明确不支持**：URL/网页抓取、PDF、DOCX 等其他格式、Anki（.apkg）、图片或图形界面。遇到时直接说明限制并停止，可建议用户粘贴纯文本或另存为 `.md`/`.txt`。

## 工作流程

1. **通读全文**：判断文章类型与结构（概念解释、方法流程、观点论证、资料笔记等）。
2. **提取候选知识点**：核心概念、原理与机制、规则与结论、方法步骤、关键区分、重要事实与数字、因果关系。跳过铺垫、修辞、重复例证和次要细节。
3. **去重合并**：同一知识点在不同段落重复出现，合并为一张；多个例证服务于同一观点时，例证不单独成卡。
4. **原子化检查**：一张卡片只讲一个知识点；候选点含两个并列重点时拆成两张。
5. **排序取舍**：按原文逻辑或重要性排序，选出真正重要的点。
6. **忠实性检查**：每条表述必须能在原文找到依据，原文没有的一律不写。
7. **写卡片并交付**。

### 数量规则（硬约束）

- 目标 **5~8 张**。
- 原文独立知识点不足 5 个时，有多少给多少，并在开头注明“原文信息有限，仅提炼 N 张”。
- 独立知识点超过 8 个时，只保留最重要的 8 个，不扩容。
- 绝不为凑数量而拆分同一知识点、添加原文没有的内容或注水。

## 卡片格式

严格使用以下 Markdown 模板，字段顺序固定：

```markdown
## 卡片 N：{标题}

- **核心知识**：{一句话陈述该知识点最关键的结论}
- **简明解释**：{2~4 句，用通俗语言补充机制、原因、适用条件或与相近概念的区别，不重复核心知识}
- **例子/自测**：{优先用原文中的例子，写作“例：……”；原文无合适例子时，出一道仅靠本卡即可回答的自测题，写作“问：……？”}
```

写作要求：

- 标题是具体知识点名（如“复利的指数增长特征”），不是章节名或空泛主题（如“关于复利”）。
- 核心知识用陈述句给出明确结论，不写“本文介绍了……”这类元描述。
- 简明解释必须提供增量信息：为什么、怎么做、边界条件或易混区分。
- **忠实于原文的边界**：解释只允许重组、通俗化原文已有的信息，禁止加入原文没有的论断、比喻、数据或评价；写完后把每条解释与原文逐句回查，删掉任何“你自己补充的常识”。
- **例子不跨点挪用**：例子必须放在它在原文中实际说明的那个知识点的卡片里；原文某处的例子只服务于该卡片，不拿来装饰其他卡片。
- 自测题的答案必须能从本卡内容直接得出，优先考查卡片中明确给出的事实（定义、数字、因果、步骤），不出无答案的开放题，不向读者索要个人经历。
- **语言整体一致**：整张输出（含固定字段名、“卡片 N”、来源行、说明文字）都使用原文的语言。英文原文时使用对应英文标签：`Card N`、`Core knowledge`、`Explanation`、`Example / self-test`、`Source`、`N cards`。
- 每张卡片脱离原文也能独立读懂。

### 单卡示例

原文片段：“复利是指收益计入本金后继续产生收益，因此长期资产呈指数增长；而单利只对原始本金计息，时间越长两者差距越大。例如年化 10% 时，本金约 7.2 年翻一倍。”

合格卡片：

```markdown
## 卡片 2：复利带来指数增长

- **核心知识**：复利把每一期收益并入本金继续生息，长期资产呈指数而非线性增长。
- **简明解释**：单利只对原始本金计息，复利对“本金+累计收益”计息，时间越长两者差距越大；年化 10% 时约 7.2 年翻倍。
- **例子/自测**：例：年化 10%，本金约 7.2 年翻一倍。
```

## 交付格式

```markdown
# 知识卡片：{文章标题或主题}

> 来源：{文件名或“粘贴文本”}　共 N 张

{卡片 1}
{卡片 2}
……
```

默认直接在对话中输出；用户要求保存时，写入与输入同目录的 `{文件名}_cards.md`。交付后可附一句说明：被合并的重复点、被舍弃的次要内容，或信息不足的情况。

## 质量自检（交付前逐项确认）

- [ ] 每张卡片只有一个知识点，且四个字段齐全
- [ ] 所有内容均可在原文找到依据，解释中无原文没有的论断、比喻、数据或评价
- [ ] 重复内容已合并，没有两张卡片讲同一点；例子没有跨知识点挪用
- [ ] 数量在 5~8 之间；不足时已如实说明，未凑数
- [ ] 例子来自原文，或自测题可凭卡片本身作答（答案是卡内明确事实）
- [ ] 语言与原文一致（含字段标签），卡片脱离原文可独立读懂
