# make-knowledge-cards

一个纯指令型 Agent Skill：把文章提炼成 5\~8 张可独立复习的知识卡片，无需任何脚本或第三方依赖。

## 项目解决什么问题

读完文章后 "看懂了但记不住"，常见原因是被动重读、划线不会主动提取知识；而手工整理笔记又耗时。本 Skill 让 Agent 自动完成文章的提炼与重组：识别真正重要的知识点、合并重复内容、按统一格式输出成卡片，可直接用于复习、速读和做学习笔记。

## 主要功能



* **两种输入**：直接粘贴的文章文本，或本地 `.md` / `.txt`（UTF-8）文件。

* **固定卡片结构**：每张卡片包含 标题、核心知识、简明解释、例子或自测问题 四个字段。

* **质量规则**：


  * 只提取真正重要的知识，一张卡片只讲一个知识点；

  * 同一知识点在原文多处重复时合并为一张，不重复成卡；

  * 严格忠于原文，不编造原文没有的论断、例子或数据；

  * 目标 5\~8 张；原文独立知识点不足 5 个时如实少做并注明，绝不为凑数量注水；超过 8 个时只保留最重要的 8 个。

* **语言跟随原文**：中文原文输出中文卡片，英文原文输出英文卡片（含字段标签）。

* **自测设计**：优先使用原文中的例子；没有合适例子时，给出一道仅凭卡片本身即可作答的自测题。

* **暂不支持**：网页抓取、PDF/DOCX 等其他文件格式、Anki（.apkg）导出、图形界面。

## 安装方法

本 Skill 不依赖任何运行时库，安装即复制文件夹：



1. 将本仓库中的 `skills/make-knowledge-cards` 整个文件夹复制到 Agent 扫描的 Skill 目录下，保持文件夹名不变。

2. 以豆包工作环境为例，可复制到：

* `…/workspace/.user_skills/make-knowledge-cards`（用户级 Skill 目录），或

* `~/Doubao/skills/make-knowledge-cards`。

1. 重启或刷新 Agent 会话后，Skill 即可被识别（识别依据是 `SKILL.md` 中的 name 和 description）。

## 使用方法



* **粘贴文本**：直接把文章发给 Agent，并说明要做知识卡片，例如：


  * “把下面这篇文章做成知识卡片：……”

* **本地文件**：给出文件路径，例如：


  * “用 make-knowledge-cards 处理 `notes/article.md`”

* **输出位置**：默认直接在对话中输出；如需保存，明确告知 Agent，会在原文同目录生成 `{文件名}_cards.md`。

* 遇到 URL、PDF、DOCX 等不支持的输入时，Agent 会说明限制；可将内容粘贴为纯文本或另存为 `.md`/`.txt` 后再试。

## 输入输出示例

**输入**（文章片段）：

> 复利是指收益计入本金后继续产生收益，因此长期资产呈指数增长；而单利只对原始本金计息，时间越长两者差距越大。例如年化 10% 时，本金约 7.2 年翻一倍。

**输出**（单张卡片示例）：



```
\## 卡片 2：复利带来指数增长

\- \*\*核心知识\*\*：复利把每一期收益并入本金继续生息，长期资产呈指数而非线性增长。

\- \*\*简明解释\*\*：单利只对原始本金计息，复利对“本金+累计收益”计息，时间越长两者差距越大；年化 10% 时约 7.2 年翻倍。

\- \*\*例子/自测\*\*：例：年化 10%，本金约 7.2 年翻一倍。
```

完整输出还包含标题行（`# 知识卡片：……`）、来源与卡片数量（`> 来源：……　共 N 张`），以及信息不足时的说明。完整示例见 `tests/outputs/`。

## 目录结构



```
skills/make-knowledge-cards/

├── SKILL.md            # Skill 主指令：工作流程、卡片格式、数量规则、质量自检

└── agents/

&#x20;   └── openai.yaml     # Agent 界面配置：展示名、简短描述、默认提示词

tests/

├── inputs/             # 3 篇测试文章：中文概念科普、中文流程方法、英文短文本

└── outputs/            # 对应的卡片输出样例
```

## 验证

`tests/` 覆盖三种典型场景：含重复内容的中文概念科普（8 张）、步骤型中文方法文章（8 张）、知识点不足 5 个的英文短文本（如实输出 3 张并注明）。

若环境中装有官方 `skill-creator-for-work`，可用其校验脚本检查 Skill 结构：



```
python /path/to/skill-creator-for-work/scripts/quick\_validate.py skills/make-knowledge-cards

\# 输出：Skill is valid!
```
